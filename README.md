# TranslucentTabBar

WinUI 3-приложение (MSIX, packaged), делающее панель задач Windows 11 прозрачной/полупрозрачной. Современная адаптация [TranslucentTB](https://github.com/TranslucentTB/TranslucentTB) на .NET 10 / Windows App SDK 2.4.

Публикуется в Microsoft Store как **Glassbar — Transparent Taskbar for Windows** (короткое имя Glassbar, издатель linecode.pro).
